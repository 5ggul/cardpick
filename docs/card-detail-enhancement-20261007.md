# 카드 상세 로컬 고도화 — 2026-10-07

상태: 로컬 수정·검증. 커밋, 푸시, 운영 배포, 색인 요청은 실행하지 않았다.
기준: GitHub main `38f6c5becbf44a2695081fb5dd1a6f59d5a1f4b9`, 기존 분리 작업공간 재사용.
실제 원본 저장소의 사용자 변경과 기존 작업공간의 과거 감사 문서는 수정하지 않았다.

## 변경 범위와 보존 계약

- `card-detail.html`의 head 카드 초기화 IIFE를 `card-detail.js`로 옮겨 auth → search → card-detail 순서의 defer 실행을 유지한다.
- 작은 bootstrap으로 관심카드가 참조하는 runtime 객체를 보존한다. 새 파일을 불러오지 못해도 DCL에서 서버가 넣은 카드명·세트·게임으로 같은 객체를 갱신한다.
- 서버와 동일한 카드 텍스트/속성은 불필요하게 다시 쓰지 않는다. API 조회와 가격 갱신은 생략하거나 늦추지 않았다.
- 관련 카드의 한국어 별칭과 푸터 작은 글자의 대비를 높였다. 본문 바로가기의 실제 타깃과 포커스 표시를 추가했다. 동적으로 변하는 관심카드 버튼의 접근성 이름은 실제 표시 문구를 따른다.
- 모바일 패널 내부 여백 16px, 질문 패널 데스크톱 20px. 기존 본문·디자인·링크·가격 상태·썸네일은 유지한다.
- Tailwind의 검색 대상에 새 초기화 파일을 추가했다. 재빌드 결과의 CSS 내용은 기존과 동일했다.
- 카드 SSR 캐시 키만 새 UI 버전으로 갱신했다. localhost/127.0.0.1/[::1]에서는 오래된 HTML 캐시를 우회해 로컬 편집을 즉시 확인한다. 운영 캐시 동작과 만료 시간은 유지한다.
- URL, canonical, robots, 사이트맵, 카드 색인 게이트, 가격 산식, DB 데이터는 변경하지 않았다. 본문 해시 검증은 명시한 접근성 속성과 질문 패널 스타일만 정규화한 뒤 기존 해시로 통과한다.

## 검증

전용 스타일 재빌드와 JS 문법 검사, 가격 계약·실제 DOM renderer·defer 실행순서·CGC·폰트·방법론 등 179개 테스트 통과. Git diff 공백 검사 통과.
외부 파일 실패와 정상 defer 경로는 실제 초기화/관심카드/최근조회 IIFE를 격리 실행하여 검증했다. 모의 데이터 검증이며 로그인된 계정의 원격 저장을 실행했다는 뜻은 아니다.
별도 읽기 전용 검토에서도 새 회귀는 발견되지 않았다.

Lighthouse 13.4.1, 로컬 `/cards/seaking-21`, 900px 높이, DPR 1, 모바일 기본 throttling(1280/1440은 desktop preset), 각 크기 단일 측정:

모바일 LCP 2.5초 및 375/768 성능 90점 목표는 **미달**이다. 실사용자 Core Web Vitals 측정이나 전체 카드의 성능을 보장하는 결과가 아니다.
수정 전 375px 기록은 73점/6.2초/접근성95지만 엣지 캐시가 적용된 상태였다. 수정 후는 로컬 캐시 우회 상태이므로 엄밀한 동일 조건 A/B 개선율로 인용하지 않는다.
첫 분리 실험 보고서에는 이전 HTML 캐시가 남아 새 스크립트가 없었으므로 최종 결과에서 제외했다.
Windows 임시 Chrome 폴더 정리 단계에서 EPERM 종료가 발생했지만, 최종 5개 JSON 보고서는 runtimeError 없이 생성되었고 새 초기화 파일의 요청도 확인했다. CLI 전체가 정상 종료했다고 주장하지 않는다.

실제 브라우저에서 `/cards/seaking-21`과 `/cards/phanpy-205`의 가격·관측일·신뢰도·관련 카드·최근조회·질문 링크를 확인했다. 코코리 카드에서는 320/375/768/1280/1440px 화면과 모바일 하단 패널을 캡처했고 문서 가로 넘침이 없었다. 본문 바로가기는 Tab → Enter로 main 포커스 이동을 확인했다.
관심카드 조작은 비로그인 확인창 경로에서 브라우저 입력 점검이 중단돼 완전한 UI 저장 테스트로 간주하지 않는다. 로그인이나 계정 저장은 실행하지 않았고, 해당 임시 테스트 탭만 닫았다. 메타 전달·runtime identity는 위 회귀 테스트에서 별도 검증했다.

## 남은 항목

1. 모바일 cold SSR 및 첫 화면의 폰트/데이터 응답 병목을 같은 조건에서 반복 측정해 LCP 2.5초 목표를 보완한다. 본문 삭제·가격 조회 생략·분석 기능 지연으로 점수를 조작하지 않는다.
2. 검색에서 `Phanpy`는 25건이 나오지만 `코코리`는 결과가 없었다. 페이지의 검수 별칭과 공용 검색의 연결을 다음 개선 대상으로 검토한다. 이번에는 공용 검색 소스/데이터를 변경하지 않았다.
3. 운영 배포 전에 사용자에게 로컬 결과와 미달 항목을 보여주고 별도 승인을 받는다. 로그인된 관심카드 저장은 계정 소유자의 별도 실제 확인이 필요하다.
