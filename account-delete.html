계정·데이터 삭제 요청

카드픽 이용자는 계정과 이용자 저장 데이터의 삭제를 요청할 수 있습니다. 요청은 이메일로 접수하며, 접수일 기준 영업일 14일 이내에 처리하고 결과를 회신합니다. 관련 법령상 보존 의무가 있는 최소 정보는 예외적으로 별도 기간 보관 후 폐기합니다.

최종 갱신 2026-08-29 적용 대상 카드픽 웹 · Android 앱(kr.cardpick.app) 운영자 admin@cardpick.kr

01삭제 대상 데이터

카드픽이 이용자와 연결해 보유하는 데이터는 다음과 같습니다. 요청 시 아래 항목이 모두 삭제됩니다.

구분항목처리
계정이메일, 표시 이름, 프로필 이미지 URL, Google 계정 식별자완전 삭제
커뮤니티본인이 작성한 게시글, 댓글, 좋아요 기록완전 삭제
관심 카드watchlist (저장한 카드 목록)완전 삭제
가격 알림가격 알림 설정, 임계값, 발송 이력완전 삭제
기기·앱앱 내부 저장소, 로컬 설정앱 삭제 시 자동 제거

02삭제 예외 (법령상 보존)

다음 정보는 관련 법령상 최소한의 보존 의무가 있어 지정된 기간 동안 격리 보관 후 자동 폐기합니다. 서비스 이용 목적으로는 사용하지 않습니다. - 부정 이용·도배 방지를 위한 기술 로그(익명화된 요청 기록): 최대 30일 보관 후 자동 삭제 - 「전자상거래 등에서의 소비자보호에 관한 법률」 등 관련 법령에서 사업자에게 보존 의무를 부과하는 경우 해당 항목에 한해 법정 기간 보관 현재 카드픽은 유료 결제·거래 중개 서비스를 운영하지 않으므로, 결제·계약·소비자 분쟁 관련 보존 대상 데이터는 발생하지 않습니다.

03요청 방법 A : 이메일 접수

아래 주소로 요청 메일을 보내주세요. 본인 확인을 위해 가입 시 사용한 Google 계정 이메일에서 발송해 주시기 바랍니다.

받는 사람: admin@cardpick.kr 제목: [삭제 요청] 카드픽 계정 삭제 본문: - 삭제 요청 대상: 카드픽 계정 및 모든 이용자 데이터 - 가입 이메일: (본인의 Google 계정 이메일) - 삭제 사유(선택): (자유 기재) 본인은 위 정보의 삭제를 요청합니다.

04요청 방법 B : 앱 내 요청

카드픽 Android 앱의 [설정 → 계정 → 계정 삭제] 메뉴에서도 요청할 수 있습니다. 앱에서 요청한 경우에도 본 페이지의 처리 절차·기간이 동일하게 적용됩니다.

05처리 절차

- D+0: 요청 접수. 자동 회신으로 접수 확인. - D+1~2: 본인 확인. 가입 이메일과 요청 이메일이 다를 경우 추가 확인 절차. - D+3~14: 계정·이용자 데이터 완전 삭제 수행. - D+14 이내: 삭제 완료 회신. 법령상 보존 대상이 있는 경우 항목·기간 함께 안내. 삭제 후에는 동일 이메일로 재가입이 가능하나, 이전 계정의 게시글·댓글·관심 카드 등은 복구되지 않습니다.
