이 도구가 계산하는 범위

카드별 판매 가능 가격 × 박스당 평균 출현 장수를 더하고, 그 밖의 판매 가능 가치를 합산합니다. 이 값을 실제 박스 구매가로 나눠 입력값 기준 회수율을 표시합니다.

카드픽이 봉입률을 추정하거나 박스별 수익을 자동 예측하지 않습니다. 입력값의 언어·상품·표본 조건과 가격 기준이 정확해야 비교도 의미가 있습니다.

결과에서 빠지는 비용

표시 결과는 입력값의 산술 합계입니다. 실제 손익을 보려면 다음 항목을 결과에서 별도로 빼야 합니다.

  • 판매 비용: 플랫폼·결제 수수료, 포장비, 배송비
  • 상태 차이: 인쇄선, 백화, 센터링에 따른 가격 차이
  • 미판매 위험: 참고가가 있어도 구매자를 찾지 못하는 카드
  • 시간 비용: 촬영, 등록, 문의, 포장과 분쟁 처리

자세한 비교는 박스 vs 단품 가이드에서 다룹니다.

평균 출현 장수 입력 전 확인

관측 자료를 사용할 때는 다음 조건을 먼저 확인하세요.

  • 내가 살 상품과 언어·세트·상품 종류가 같은가
  • 표본 수와 수집 시점이 공개되어 있는가
  • 특정 카드와 희귀도 전체의 수치를 혼동하지 않았는가
  • 중복 집계나 선택적으로 공개된 개봉 결과가 아닌가

출처를 확인할 수 없거나 서로 다른 상품의 자료라면 숫자를 넣지 마세요. 특정 카드가 목표라면 박스 vs 단품 선택 가이드의 단품 비교부터 진행하는 편이 안전합니다.

자주 묻는 질문

이 계산기의 회수율은 실제 수익률인가요?
아닙니다. 사용자가 입력한 가격과 평균 출현 장수를 단순 계산한 추정치입니다. 수수료, 배송비, 상태 차이와 미판매 위험은 별도로 반영해야 합니다.
카드픽 참고가를 그대로 판매 가능 가격으로 써도 되나요?
그대로 쓰지 마세요. 카드픽 참고가는 해외 가격의 원화 환산값이며 국내 실거래가가 아닙니다. 같은 언어와 상태의 실제 거래 가능 가격으로 조정하세요.
평균 출현 장수는 무엇을 확인해야 하나요?
언어, 세트, 상품 종류, 표본 수와 조사 시점이 같은 자료인지 확인해야 합니다. 출처를 확인할 수 없으면 결과를 구매 근거로 쓰지 마세요.
입력값이 서버에 저장되나요?
계산을 위해 입력한 값은 서버로 보내거나 저장하지 않고 현재 브라우저에서만 처리합니다. 카드 검색을 사용할 때는 검색어로 카드픽 데이터 API를 조회합니다.

참고

본 계산기는 입력한 값의 산술 결과를 보여주는 참고 도구입니다. 실제 개봉 결과와 판매 수익을 보장하지 않습니다. 카드픽 가격의 범위와 갱신 방식은 방법론에서 확인하고, 목적별 선택 기준은 박스 vs 단품 가이드를 참고하세요.
