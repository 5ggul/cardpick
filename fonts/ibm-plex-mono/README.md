# IBM Plex Mono v20

Unmodified WOFF2 files supplied by Google Fonts for weights 400, 500 and 600.
All fifteen Latin, Latin Extended, Cyrillic, Cyrillic Extended and Vietnamese
faces are retained. CSS unicode ranges download only the needed faces.

Source stylesheet, checked 2026-09-30:
https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400;500;600&display=swap

Font binaries retain their versioned Google Fonts filenames. No outlines,
names, weights or font metrics were edited. The existing typeface is served
locally to avoid a cross-origin stylesheet and font-request chain.
